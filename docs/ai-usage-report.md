# AI Usage Report

## 1. Tools Used & Use Cases

### ChatGPT

I used ChatGPT as an AI-assisted development and learning tool during Assignment 2.
I used ChatGPT for several purposes throughout the development process.

### Understanding the Assignment

I used ChatGPT to help me understand the Assignment 2 requirements and divide them into smaller tasks.

This helped me identify the main requirements, including the About Me section, Projects section, Contact form, responsive design, JavaScript interactivity, GitHub repository, and documentation.

### Website Planning

I used ChatGPT to get suggestions for improving the portfolio website developed in Assignment 1.
I decided to keep the existing website structure and design while adding new interactive features.

### Interactive Features

I used ChatGPT to explore different ways to make the website more interactive.

I decided to add a project filtering feature that allows users to display projects based on selected technologies.

ChatGPT helped explain how JavaScript can use event listeners, data attributes, and DOM manipulation to update the displayed projects.

### HTML Assistance

ChatGPT provided suggestions for organizing the HTML structure and adding the project filtering buttons.

I reviewed and adjusted the placement of the filtering buttons and feedback message to fit the existing Projects section.

### CSS and UI Design

In assignment 1: I used ChatGPT to help understand and apply CSS Grid, Flexbox, and media queries. I also requested design changes and customized the website to rearrange the placement of texts 

In assignment 2: 
I used ChatGPT to help understand and apply CSS styling for interactive elements. I also requested suggestions for improving the appearance of filter buttons, hover effects, animations, and form feedback messages.
I kept the original pink, black, and white color palette.

### JavaScript Assistance

ChatGPT helped explain how JavaScript can be used to add interactive features.

I used JavaScript to implement features such as the dark/light theme.

I used ChatGPT to review and improve JavaScript code for:
- Dynamic project filtering
- Saving theme preferences using localStorage
- Contact form validation
- Checking the Error and success feedback messages that I have wrote 


### Debugging and Problem Solving

I used ChatGPT to help identify and understand errors in my JavaScript and HTML code.

For example, I reviewed problems related to variable names, project filtering attributes, and contact form validation.

I also used ChatGPT to understand why the contact form displayed a success message when the message field was empty.

After reviewing the validation logic, I added a condition to check whether the message field was empty.

I also reviewed the theme switching logic and the use of localStorage to remember the selected theme

### Documentation

I used ChatGPT to help organize and fix grammar mistakes in the README, AI usage report, and technical documentation.

I reviewed the documentation and made sure that it reflected the actual implementation of my project.

## 2. Benefits & Challenges

### Benefits

Using AI helped me understand the assignment requirements more clearly and organize the development process.

It provided useful examples and explanations for HTML, CSS, JavaScript, and responsive design.

AI also helped me explore different design ideas and understand how different front-end technologies work together.

Another benefit was that I could ask follow-up questions when I did not understand a requirement or technical concept.

It also helped me discover knew features that I can do using HTML, CSS, JavaScript. 

### Challenges

AI-generated suggestions are not automatically correct or suitable for every project.

Some suggestions needed to be changed to match the assignment requirements and my preferred design.

For example, I changed the structure and appearance of the portfolio and selected my own preferred design specification. Also, I adjusted the placement of the project filtering buttons and corrected parts of the contact form validation.

I also needed to understand how the JavaScript conditions worked to identify why some validation messages were not displayed correctly. 

I also needed to test the website myself because AI suggestions cannot replace actual browser testing.

## 3. Learning Outcomes

Through this assignment, I improved my understanding of front-end web development and JavaScript interactivity.
I learned how event listeners can respond to user actions and how DOM manipulation can update webpage content.
I also learned how data attributes can store information about project technologies for filtering.
Using localStorage helped me understand how a browser can remember user preferences between visits.
I improved my understanding of form validation, conditional statements, and displaying feedback messages.
I also learned how AI can support software development while still requiring the developer to understand, review, modify, and test the generated suggestions.

## 4. Responsible Use & Modifications

I used AI as a supporting tool rather than submitting its suggestions without reviewing them. I reviewed the generated HTML, CSS, and JavaScript and made changes based on the assignment requirements and my personal preferences. I kept the original portfolio content, projects, and color palette. I also adjusted the structure of the Projects section, reviewed JavaScript variable names, and improved the contact form validation. I used AI explanations to understand the purpose of the code and the reasons behind the changes. Before submitting the assignment, I will test the interactive features and responsive layout to check that the website works correctly. This process helps ensure that I understand the final solution and use AI responsibly and transparently.
